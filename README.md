# FS-TUS-2026
This repository documents the electronics systems developed by the Formula
Student electronics team. It contains electrical architecture documentation,
wiring diagrams, released PCB and electrical schematics, shutdown-system
designs, testing procedures, fault-finding guides, prototype information, and
supporting measurements.

The repository also includes software for the vehicle’s display systems,
including code for presenting sensor data, GPS information, and other
real-time vehicle parameters. Additional resources include voltage-monitoring
software, simulation files, test results, and documentation for manufacturing,
testing, and scrutineering.

The purpose of this repository is to provide a record of the
electronics work completed by the team so far. It supports future development,
troubleshooting, testing, technical handover, and continued improvement of the
vehicle’s electrical systems.

The schematics in this public repository are provided as released PDF
documents for viewing and reference. Editable design files are not included.
